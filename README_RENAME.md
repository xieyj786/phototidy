# PhotoRename 照片重新命名工具

`photorename.py` 是一个基于 Tkinter 的照片批量重新命名工具。程序递归扫描多层目录中的照片文件，根据 EXIF 拍摄时间、相机信息和 GPS 信息生成便于整理的中文文件名。

## 运行环境

```bash
python3 -m pip install -r requirements.txt
python3 photorename.py
```

程序支持以下照片格式：

- `.jpg`
- `.jpeg`
- `.heic`
- `.heif`

读取 HEIC/HEIF 的 EXIF 信息依赖 `pillow-heif`。未安装该依赖时，程序仍可启动，但相关文件的读取能力可能受限。

## EXIF 信息读取

程序读取以下信息：

- 相机制造商（EXIF `Make`）
- 相机型号（EXIF `Model`）
- 拍摄时间，优先读取 `DateTimeOriginal`，其次读取 `DateTimeDigitized`
- GPS 纬度、经度

没有可解析的 EXIF 拍摄时间时，不使用文件修改时间代替，并跳过该文件。
对于保留了有效 GPS、但仅有 EXIF `DateTime`（标签 306）的手机导出照片，
程序会将该字段作为备用拍摄时间；没有 GPS 时仍不会使用 306，避免把元数据修改时间误当作拍摄时间。

## 命名规则

文件名保留原文件扩展名的小写形式，序号 `NNNN` 为四位数字，并按“文件名前缀 + 年份”分别从 `0001` 开始计数。

### 1. 有完整相机信息和 GPS

当 EXIF 同时包含相机制造商、相机型号、拍摄时间和有效 GPS 信息时，先根据制造商和型号判断设备类型：

- 手机：`IMG_YYYYMMDD_地理位置_NNNN`
- 独立相机：`DSC_YYYYMMDD_地理位置_NNNN`

其中：

- `YYYYMMDD` 是拍摄日期；
- `地理位置` 使用 GPS 反向地理编码得到的景点、行政区或国家名称，并优先使用中文名称；
- `NNNN` 按 `IMG` 或 `DSC` 前缀和拍摄年份分别编号。

示例：

```text
IMG_20240815_北京_0001.jpg
DSC_20240815_开普敦_0001.jpeg
```

### 2. 有完整相机信息但没有 GPS

当 EXIF 同时包含相机制造商、相机型号和拍摄时间，但没有有效 GPS 信息时：

- 手机：`IMG_YYYYMMDD_HH-MM-SS_NNNN`
- 独立相机：`DSC_YYYYMMDD_HH-MM-SS_NNNN`

示例：

```text
IMG_20240815_13-24-05_0001.jpg
DSC_20240815_13-24-05_0001.jpeg
```

### 3. 信息不完整但有拍摄时间

当 EXIF 有可解析的拍摄时间，但相机制造商、相机型号或其他相关信息缺失、不完整时，使用 `PIC` 前缀：

- 有 GPS：`PIC_YYYYMMDD_地理位置_NNNN`
- 无 GPS：`PIC_YYYYMMDD_HH-MM-SS_NNNN`

示例：

```text
PIC_20240815_上海_0001.jpg
PIC_20240815_13-24-05_0002.jpg
```

### 4. 跳过条件

以下文件不进行命名处理：

- 没有 EXIF 数据的文件；
- 没有可解析拍摄时间的文件；
- 不属于 `.jpg`、`.jpeg`、`.heic`、`.heif` 的文件。

程序不会根据文件修改时间推测拍摄时间。

## GPS 地理位置

GPS 信息通过 Nominatim/OpenStreetMap 进行反向地理编码，并尝试使用中文名称。相同坐标区域会使用缓存，减少重复查询。

如果无法取得地理位置名称，程序会使用 `无GPS` 作为文件名中的位置占位文本，以确保文件仍能完成命名。

## 文件冲突处理

程序不会覆盖已有文件。如果目标文件名已存在，会递增文件名末尾的四位序号，保持序号始终作为文件名最后的语义组成部分。

## 运行日志

程序在所选图片库根目录生成唯一编号的日志文件：

```text
photorename_log_YYYYMMDD_NNN.txt
```

日志包括：

- 扫描图片总数；
- 符合命名条件的文件数；
- 成功重新命名数；
- 跳过数和失败数；
- 每个重命名文件的原路径与新路径；
- `.jpg`、`.jpeg`、`.heic`、`.heif` 各自的总数、成功重命名数和未重命名数；
- 错误明细和程序运行耗时。

默认情况下，日志不记录每个文件的旧名称与新名称对应关系，以减少日志体积。程序界面中的“调试日志：记录旧名称/新名称明细”选项默认关闭；仅在需要排查问题时勾选，日志才会增加逐文件的改名前后名称明细。

## 操作说明

1. 启动程序。
2. 选择照片库根目录。
3. 点击“开始重新命名”。
4. 任务完成后，根据界面提示和根目录中的日志核对处理结果。

处理过程中可以点击“停止”。已经完成的重命名不会回滚，尚未处理的文件会保留原名。
